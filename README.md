# David 韦国辉网页版作品集

双击 `index.html` 即可本地打开。网页为纯静态文件，不需要安装依赖，也可以上传到 GitHub Pages、Netlify、Vercel 或任意网站服务器。

当前版本采用全站黑色视觉主题，首页 WELCOME 为彩色霓虹液态玻璃效果，并使用最新彩色证件照。

首页四张作品卡使用独立 Z 轴深度、立体侧边和扇形展开动效；文件夹卡通徽章的双眼会跟随鼠标方向移动。

卡片默认按文件夹收纳状态层叠，鼠标进入文件夹后横向展开；阴影采用低透明度柔光。WELCOME 使用随页面打包的圆润粗体与多层液态玻璃高光效果。

文件夹现为前后双层结构，前袋使用半透明磨砂玻璃；收合时作品卡仅露出顶部。个人介绍区包含技能概述、AI 能力、13K–25K 期待薪资，并预留成绩与成果位置。

首页 WELCOME 已替换为用户提供的液态玻璃图片 `assets/original/welcome-liquid.png`。文件夹收合状态会裁切卡片底部，避免卡片穿出文件夹；展开时恢复完整卡片。

文件夹后挡板与凸起耳朵采用连体不透明蓝色，前袋保留磨砂玻璃。卡片展开幅度已收紧，阴影调整为大范围低透明度柔光，卡片标题改为中文。

作品卡比例为 6:4（3:2），并位于不透明后袋与磨砂玻璃前袋之间的真实夹层。

收合时四张卡片主体均置于磨砂前袋内部，仅露出顶部边缘。卡片使用蓝紫与青色柔光阴影，中文标题位于左下角并带文字阴影。

四张卡片在收合状态按等距横向错位排列，并向袋内下沉，左右边缘均保持在文件夹范围内。磨砂前袋透明度约 70%，采用 22px 背景模糊。


## 文件结构

- `index.html`：网页内容
- `styles.css`：视觉样式与响应式布局
- `script.js`：首页卡片动效、滚动动效与项目弹窗
- `assets/`：作品图片
